# Fara'id AI Public Production Package

Recommended first deployment:
- API + PostgreSQL: Railway
- Web: Vercel (or Railway)
- Domain: app.yourdomain.com / api.yourdomain.com

The included files are deployment scaffolding. You still need to install dependencies,
configure your secrets, push to GitHub, connect the services, and complete the production
rule/evidence approval gate before opening the service to the public.
