# Fara'id AI — Full V1 Foundation

Multilingual Islamic inheritance platform:
- Next.js web app
- NestJS API
- PostgreSQL + Prisma
- Deterministic Fara'id calculation package
- Evidence/source layer
- Scholar/admin approval workflow
- AI adapter layer
- Hausa, English, Arabic, French, Yoruba, Hindi, Chinese

## Safety boundary
The calculation engine is deterministic and separate from the AI. AI may extract facts,
translate, and explain approved results, but it must never invent or override a share.

Rules/evidence must be reviewed by qualified scholars before production activation.
